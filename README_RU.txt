GRUPPE SECHS — РАБОЧАЯ ВЕРСИЯ ПОРТАЛА
====================================

В этой версии нет тестовых аккаунтов, паролей по умолчанию и локального хранения данных в браузере.
Система использует сервер Python и централизованную базу SQLite.

ЧТО НУЖНО
---------
- Python 3.10 или новее
- Сервер/компьютер, который будет постоянно работать
- Для публичного доступа из интернета: домен и HTTPS reverse proxy (например, Caddy или Nginx)

ПЕРВЫЙ ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ
---------------------------------
1. Распакуйте архив в отдельную папку.
2. Откройте терминал в этой папке.
3. Создайте первого администратора:

   python server.py create-admin

   Программа спросит имя, email и пароль. Пароль должен содержать не менее 12 символов.
   Логин и пароль не зашиты в файлы проекта. Не отправляйте пароль другим людям.

4. Запустите сервер локально:

   G6_COOKIE_SECURE=0 python server.py

   На Windows PowerShell:

   $env:G6_COOKIE_SECURE="0"
   python server.py

5. Откройте в браузере:

   http://127.0.0.1:8080

6. Войдите по email и паролю, которые вы задали на шаге 3.
7. В разделе «Сотрудники» создайте учётные записи офицеров и других руководителей.
   Временный пароль передавайте сотруднику безопасным способом.

КАК РАБОТАЮТ РОЛИ
-----------------
- Руководство: создаёт аккаунты сотрудников, видит штат, объекты, журнал смен и все отчёты.
- Офицер охраны: видит назначенные/свободные объекты, фиксирует свои смены и отправляет служебные отчёты.
- Клиент: самостоятельно регистрируется, видит только свои объекты и может добавлять новые.

БАЗА ДАННЫХ И РЕЗЕРВНЫЕ КОПИИ
-----------------------------
Основной файл базы: gruppe6.sqlite3 (создаётся автоматически в папке проекта).
Делайте регулярные резервные копии при остановленном сервере, сохраняя файл базы и, если существуют,
сопутствующие файлы gruppe6.sqlite3-wal и gruppe6.sqlite3-shm. Экспорт JSON доступен руководству
внутри панели управления; он не содержит паролей и их хешей.

ПУБЛИЧНЫЙ ЗАПУСК (ВАЖНО)
------------------------
Не выставляйте порт 8080 напрямую в интернет и не используйте локальный режим с
G6_COOKIE_SECURE=0 на публичном сервере. Для реальной работы:
- размещайте приложение за HTTPS reverse proxy (Caddy/Nginx);
- оставьте G6_COOKIE_SECURE=1 (значение по умолчанию);
- ограничьте доступ к серверу и файлу базы данных;
- настройте автоматические зашифрованные резервные копии;
- регулярно обновляйте ОС и Python;
- проверьте применимые требования к персональным данным и срокам их хранения.

По умолчанию сервер слушает 127.0.0.1:8080. Для настройки можно задать переменные окружения:
G6_HOST, G6_PORT, G6_DB_PATH, G6_COOKIE_SECURE, G6_SESSION_HOURS.

ОГРАНИЧЕНИЕ ТЕКУЩЕГО КОМПЛЕКТА
-----------------------------
Приложение и серверная база готовы для запуска на одном сервере, но сам сервер ещё не размещён
в интернете и домен/HTTPS не настроены. Поэтому после скачивания сайт не становится автоматически
общедоступным: нужно выполнить настройку выше и разместить сервер на хостинге/VPS.

УПРОЩЁННЫЙ ЛОКАЛЬНЫЙ ЗАПУСК
---------------------------
Windows: запустите START_LOCAL.bat.
Linux/macOS: выполните ./start_local.sh.
Эти скрипты отключают Secure-cookie только для локального тестирования на localhost.
Не используйте их при публикации в интернете.
