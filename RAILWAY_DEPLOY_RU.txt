GRUPPE SECHS — ПУБЛИКАЦИЯ НА RAILWAY
====================================

ВАЖНО: этот архив подготовлен для публикации на Railway. Нельзя просто перетащить ZIP в браузер хостинга: сначала распакуйте архив и загрузите файлы проекта в GitHub-репозиторий.

1. Откройте https://github.com/new и создайте Private repository, например gruppe6-portal.
2. Распакуйте архив. Загрузите в репозиторий ВСЕ файлы и папки из этой папки (не сам ZIP).
3. Откройте https://railway.com/new и выберите Deploy from GitHub Repo.
4. Подключите GitHub и выберите репозиторий gruppe6-portal. Railway соберёт приложение по Dockerfile.
5. В настройках сервиса откройте Volumes и добавьте Volume с Mount Path: /data.
   Это ОБЯЗАТЕЛЬНО: без постоянного тома база SQLite может пропасть при пересоздании/переразмещении сервиса.
6. В Variables добавьте три переменные для первого запуска:
   G6_ADMIN_NAME = имя администратора
   G6_ADMIN_EMAIL = ваш email
   G6_ADMIN_PASSWORD = уникальный пароль не короче 12 символов
   Не используйте пароль из примеров и никому его не отправляйте.
7. Убедитесь, что G6_COOKIE_SECURE не установлена в 0 (по умолчанию включена).
8. Нажмите Deploy. В Settings → Networking → Generate Domain создайте публичный домен Railway.
9. После успешного первого запуска удалите G6_ADMIN_PASSWORD из Variables и выполните Redeploy. Удаление переменной не удаляет уже созданного администратора.
10. Откройте выданный HTTPS-домен и войдите по G6_ADMIN_EMAIL и паролю, который задали.

ПЕРВЫЙ АДМИНИСТРАТОР
--------------------
При первом запуске сервер создаёт руководителя только если в базе ещё нет пользователя с ролью manager. Пароль хранится в виде хеша. После создания удалите G6_ADMIN_PASSWORD из переменных Railway.

БАЗА ДАННЫХ
-----------
SQLite хранится в /data/gruppe6.sqlite3. Постоянный Railway Volume должен быть смонтирован именно в /data. Не удаляйте этот Volume, иначе потеряете базу.

СТОИМОСТЬ И ОГРАНИЧЕНИЯ
-----------------------
Railway не гарантирует постоянный бесплатный хостинг: использование тарифицируется по текущему тарифу/кредитам. Перед Deploy проверьте цену в своём аккаунте. Не вводите платёжные данные и не подтверждайте оплату без согласования с родителем/опекуном.

ПЕРЕД РЕАЛЬНЫМ ИСПОЛЬЗОВАНИЕМ
-----------------------------
Настроить резервные копии Volume, ограничить доступ к аккаунту хостинга, использовать уникальный пароль, проверить HTTPS-домен и провести тест входа/ролей. Не загружайте реальные персональные данные до этих проверок.
